# Steady Cut Lawns Website

Professional, mobile-responsive landing page for Steady Cut Lawns lawn mowing service.

## Deployment

### Netlify (Recommended)
1.  **Drag and Drop:** Drag the contents of this folder into the [Netlify Drop](https://app.netlify.com/drop) area.
2.  **Git Integration:**
    - Connect this repository to Netlify.
    - Set the **Build command** to: (leave blank)
    - Set the **Publish directory** to: `.` (or root)

### Manual Hosting
Upload all files to any static web host (S3, GitHub Pages, Vercel, etc.).

## Local Development
Run a local server to view the site:
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.
